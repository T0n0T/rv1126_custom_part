# 02 — 真板 RockIVA 探针

**What to build:** 在真实 RV1126B 上运行一个不属于产品路径的 RockIVA 探针，确认人体检测、视频跟踪和帧所有权可以稳定工作。

**Blocked by:** 01 — 基线与回滚开关。

**Status:** in progress（CPU-NV12 与隔离采集 DMA-BUF 生命周期子门禁通过；有人场景、重启和主视频隔离待验证）

2026-08-27 已完成主机侧探针、交叉编译和连接门禁检查；历史连接阻塞保留在
`docs/people-flow-alarm/t1-board-blocker.md`。2026-08-28 已在目标板完成 CPU-NV12
PFP/CLS8 探针，2026-08-31 在隔离 `/dev/video25` 完成原生 V4L2 MMAP/EXPBUF 到
RockIVA 的 30 帧 DMA-BUF 生命周期探针，并连续运行两次 30 帧停止/重启边界复测。
两次均未检测到人，只能证明导出、释放、短时停止和格式恢复路径，不解除有人场景
门禁。探针默认会在
没有 person 或没有 `TRACKING` 状态时返回失败，避免仅凭 SDK 调用成功误过门禁；
同一 `objId` 生命周期和 ID switch 质量仍由真板代表性场景验收。

- [ ] 在候选分辨率和采样率下取得稳定 person 检出及 `objId/state` 生命周期。
- [ ] 固化经过测量的模型、结果模式、核心掩码、帧格式和输入方式。
- [ ] 证明 push、release callback、停止和重启无泄漏、重复释放或悬空引用（隔离节点
      的停止、回收和原格式恢复已通过，完整采集重启和异步回调仍待验证）。
- [ ] 证明分析分支关闭点播后仍可运行，且启停不影响主视频。
