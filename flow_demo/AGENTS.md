# flow_demo 协作约定

## 项目范围

- 本目录是面向 RV1126B 售卖柜物体出入检测 Demo 的独立项目。
- 本项目的改动仅限 `flow_demo/`；不得顺手修改上级目录中的 `media_engine`、GB28181 或 SDK 生产流程。
- 当前阶段为需求与技术验证。没有用户明确要求时，不把设计文档中的步骤当作已实现功能。
- 用户素材、模型、标注和运行结果均视为需保留的数据；不覆盖或删除已有数据。

## 代码与源码复用

- 代码发现优先使用 codebase-memory MCP 图工具；涉及源码文本、配置、构建文件或许可证时，再检查对应文件。
- 从 `wvp-ssv` 复制源码前，先记录源仓库 commit、文件清单及许可证；不得让构建依赖 SSV 工作树路径。
- 在本项目中维护经过裁剪或修改的副本，并记录与来源版本的差异；保留上游要求的许可证和声明。
- SSV 的推理抽象允许在本项目中调整以支持 RKNN 原生量化张量；SSV 的 ONNX Runtime、TensorRT、Runner、Agent、Redis 和知识库不因此自动纳入范围。

## 设计与实现

- 用户文档使用中文；代码标识、配置键和命令保留原文。
- 新功能或跨模块改动先更新 `docs/spec.md` 与 `docs/plan.md`，再实现。
- C++ 跟踪、区域穿越与事件语义应可脱离 GStreamer 单元测试；插件负责帧、PTS 和元数据适配。
- 文件回放与实时输入的丢帧语义必须区分；事件时间以源视频 PTS 为准。
- 不确定轨迹不得静默转换成确定事件；不得用前后库存差推断未观察到的逐次动作。

## 验证与报告

- 按改动范围运行针对性测试；分别报告 PC、交叉编译、板端文件回放和实时摄像头验证状态。
- 未实际运行的测试、模型转换或板端验证不得描述为通过。
- 保留工作树中与任务无关的改动；未经明确要求，不提交、不推送、不执行破坏性 Git 操作。
