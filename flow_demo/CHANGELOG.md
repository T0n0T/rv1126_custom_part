### 轻量 INT8 模型切换

- 实时/文件入口支持本项目单类别 YOLOv8 六头 INT8，并保留默认 YOLO26 双输出 INT8；按查询到的节点名、形状、类型及量化参数选择后处理，通过 `MODEL` 配置切换。
- `helmet-yolov8n-heads-int8-eval` 完成 900 帧摄像头测试：检测 **29.881 FPS**、预览 **29.869 FPS**，RKNN 阶段平均 **16.543 ms**，预处理 **6.227 ms**，后处理 **0.330 ms**。901 个 DMA 预览输出全部被 KMS 渲染，检测/轨迹的帧号和 PTS、会话摘要及正常停止检查通过。
- 对照的 YOLO26 持续运行完成 12709 帧检测，检测 **7.570 FPS**、预览 **29.996 FPS**，RKNN 阶段平均 **120.270 ms**。两次测试使用相同相机、尺寸、方向与色序配置，未进行真实柜口动作验收。
- 新程序在三帧相同输入上的 YOLO26 结果与旧程序逐字节一致；六头原生 INT8 输出与 NumPy DFL/NMS 对照一致。相关 PC 测试共 18 项通过，真实板端张量的 ASan/UBSan 检查通过。
- 三张柜口样本在置信度 0.25 时，YOLO26 检出数量为 **0/0/1**，YOLOv8n 为 **0/0/0**。样本不足以计算精度指标，速度提升不能代表柜口效果通过。轻量模型只输出 `helmet`，不检测 `head`。

模型兼容表、切换命令及详细统计见 [摄像头屏显说明](docs/board-camera-demo.md)。本轮证据目录为 `runs/board-camera/model-swap-20261113-parity/` 和 `runs/board-camera/live-20261113-yolov8-int8-smoke/`。

### 实时摄像头、事件与 DMA 预览

- 接通板载 IMX415 摄像头的 AIQ、YOLO26 INT8、BoT-SORT、三区穿越事件和 KMS 显示。主入口为 `board/rknn_yolo26_infer.c`，事件适配位于 `board/flow_events.cpp`，运行参数位于 `board/camera.env`。
- 屏幕增加三区、跟踪 ID、待穿越状态、取出/放入/不确定计数及 AI 结果年龄；事件使用检测源帧的 PTS，过时超过 400 ms 的框隐藏。未标定区域明确显示 DEBUG，正式计数保持为 0。
- 将预览与推理解耦，使用 V4L2 DMA-BUF → RGA → DMA-BUF → KMS。预览由旧版 **7.086 FPS** 提升至约 **30 FPS**；运行中回读 DRM，确认输出 framebuffer 实际使用 DMA 导入。检测分支仍有 CPU 预处理和输入复制。
- 60 帧短测预览 **29.251 FPS**、检测 **7.512 FPS**，235 个 DMA 输出全部渲染；约 140 秒长测完成 1057 帧检测，预览 **29.965 FPS**，4206 个 DMA 输出全部渲染，正常退出后摄像头与 DRM 无残留占用。
- 增加实时机位截图标定工具、旋转/尺寸约束和显式 DEBUG 示例；同一事件核心在 PC 与 RV1126B 上验证往返、观测缺口、多目标合并、异常退出与空会话。合并日志使用 `upsert` 和 `delta_count` 避免重复累计。
- 为避免多轮测试占满 `/tmp`，新运行结果移至 `/userdata/flow_demo/board-camera/`；模型按 SHA-256 缓存在 `/userdata/flow_demo/models/`，传输和复用时用 MD5 校验。保留旧运行结果及其管理方式。

### 颜色与方向修复

- 摄像头初始化对齐 `media_engine` 的 IQ 目录、normal/day 场景、normal 工作模式与自动对焦，独立 Demo 不修改生产服务。
- 同一 AIQ 会话下的 RGB/NV12 对照定位到此板 RGB24 口实际输出 **BGR**。按 full-range BT.601 转换 NV12 参考后，修复前原顺序/交换红蓝的 MAE 为 **4.206/0.326**；修复后 C 预处理输出的 RGB 对照 MAE 为 **0.323**。
- 增加 `CAMERA_COLOR_ORDER`，RGA 按 BGR 解读采集 buffer，检测预处理和干净截图输出真正 RGB，文件输入的 RGB 契约保持一致。
- 分开相机与整屏旋转，最终默认 `CAMERA_ROTATION=180`、`SCREEN_ROTATION=270`，修正相机上下左右倒置并保持横屏文字、框和区域同向。原生面板 480×800，逻辑横屏 800×480；既有正式 profile 不自动改写。
- 颜色/方向修复后的 90 帧测试预览 **29.585 FPS**、检测 **7.597 FPS**，352 个 DMA 输出全部渲染。RGB/BGR 的四种旋转、stride、缩放及完整图层映射测试、ASan/UBSan 和交叉编译通过。

详细定位、截图坐标和运行证据见 [摄像头屏显说明](docs/board-camera-demo.md)。

- 按指定改用 `comp-2-freeze10.onnx`，YOLO26l、640×640、`helmet/head` 两类。完整图 `[1,300,6]` 虽可加载推理，但坐标与分数混合 INT8 量化导致分数/类别归零。

- 增加 PC 解码、保存源 PTS/letterbox、分批推送 RGB、板端推理及拉回合并结果的入口；完成 3 帧、30 帧及单项取出整片 **168 帧**测试。
